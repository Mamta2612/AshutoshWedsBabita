# Ashutosh & Babita — Wedding Invitation

A responsive, animated, bilingual (Hindi-first) static wedding invitation site. It uses plain HTML, CSS and JavaScript; no build step or framework is required.

## Preview locally

Open `index.html` in a modern browser. An internet connection is recommended for the Google Fonts; local fallback fonts are included.

## Publish on Vercel

1. Upload this folder to a GitHub repository.
2. In Vercel, choose **Add New → Project** and import that repository.
3. Keep the framework preset as **Other**. Leave the build command empty and set the output directory to `.`.
4. Deploy. Vercel will serve `index.html` as the site entry point.

You can also host the folder on any static web host.

## Important content check before publishing

The printed schedule has a venue ambiguity: it says all wedding functions take place at **Khavtanagar-I, Bindukhutta**, while the baraat destination is separately described as **near Windsor School, Gangapur Road, Rudrapur**. Both have been kept separate on the page and the discrepancy is visibly flagged. Please confirm the final venue wording.

A few ritual words on the photographed schedule are not perfectly legible. The page uses the clearly readable core items and timings: Mangal Poojan (auspicious time), Haldi (10:00 AM), Mehendi (7:00 PM), Baraat welcome (6:00 PM), Jaimala (night, auspicious muhurat), Var-vadhu arrival (6:00 AM), Mahila Sangeet (1:00 PM) and Preetibhoj (8:00 PM).

The countdown targets 3 December 2026 at 10:00 AM Indian time.
